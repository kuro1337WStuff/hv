# 102 · The linked kernel entry page

**PASS — offline page accounting. Linux stays non-executable.** All 4,096 bytes of the page containing the uncompressed ELF entry are file-backed and belong to `.init.text`. The containing load segment is writable and lacks execute permission. An agreeing page hash describes the bytes on disk, not their lifetime after boot.

**Independent check:** `.init.text` begins at file `0x21e8000`, VA `0xffffffff82fe8000`. The page is `0x1c000` bytes into that section, giving the same file offset `0x2204000` without using `PT_LOAD.p_offset`. Hashing that slice agreed with the load-based reconstruction. This is **not** the relocated decompressor page at `0x35c1000`.
