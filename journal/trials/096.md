# 096 · FADT IRQ9 and legacy trigger configuration

**Host PASS; no system control interrupt was asserted or delivered.** [Reservation](https://github.com/kuro1337WStuff/hv/issues/13#issuecomment-7177496854) · [card #73](https://github.com/kuro1337WStuff/hv/issues/73) · [implementation #76](https://github.com/kuro1337WStuff/hv/pull/76), [integration `d79515ab`](https://github.com/kuro1337WStuff/hv/tree/d79515ab4eb6f0f19b410c4ed7786a88fe97cfa3). Tested source tree `f1738ac07d4f78bef5b5f34512abb32caf222a24`.

The generated FADT’s `SCI_INT` field identified IRQ9. The two legacy edge/level control registers (ELCR) are **configuration**, not the PIC’s interrupt mask, a request latch or an ACPI event. Each of the 256 possible byte writes was checked separately on both ports. At `0x4d0`, writable bits read back through `0xf8`; at `0x4d1`, through `0xde`. IRQs 0, 1, 2, 8 and 13 remained edge-only. Saving/restoring the two bytes during master initialization did not consume the next initialization word.

| Replayed caller policy, starting mask `0x4498` | Set IRQ9 level | Set IRQ9 edge |
|---|---|---|
| Preserve unrelated trigger settings | `0x4698` | `0x4498` |
| Rebuild from zero | `0x0200` | `0x0000` |

The host caller followed [Linux v6.18.60 `acpi_pic_sci_set_trigger`](https://github.com/gregkh/linux/blob/v6.18.60/arch/x86/kernel/acpi/boot.c#L590-L637) and the [ELCR save/restore masks](https://github.com/gregkh/linux/blob/v6.18.60/arch/x86/kernel/i8259.c#L234-L251). An unchanged trigger setting issued no writes. Wrong port or width, including width 257, preserved state and read destination. The slave interrupt mask still read `0xff` and [PM1a status](092.md) was zero after selecting level IRQ9.

**Reproduce:** from the linked integration tree, compile and run `lab/tests/legacy_elcr_test.c`, `lab/tests/pic8259_test.c` and `lab/tests/pit_pic_test.c` separately using x64 MSVC `/O2 /std:c11 /W4 /WX /TC`. All three passed.

No changes to FADT contents, live benches, host I/O or guest dispatch. This does not supply the missing [068](068.md) guest receipts or qualify the [086](086.md) image. A level source and its path through the slave and master PICs still need separate evidence.
