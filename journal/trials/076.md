# 076 · UART integration EFI: every differing byte located (host only)

2026-11-25 · [Device integration #16](https://github.com/kuro1337WStuff/hv/issues/16) · [UART parent #6](https://github.com/kuro1337WStuff/hv/pull/6). Follow-up to [073](073.md); not a repeat of the old pass/fail oracle. Question: does any differing byte in a newly retained build lie outside the COFF timestamp? **Yes. Seven bytes differ in three fields**, not in instructions. The images are not byte-identical.

The live named refs were `44fb6247240e79ca3b3097d703adba38a3235f40` (integration) and `1946d6eb6a49b74a591e3540a586d2bd96fcdc3e` (UART); `git merge-tree --write-tree` yielded `ac4290138247faff46ceaf5aa4e0b5bb044f5d3e`. A clean offline `firmware\build.cmd l1-uart-thre` from that tree produced the candidate. No timestamp override, binary edits or ignored-byte mask. The reference came from `EFI/BOOT/BOOTX64.EFI` in the FAT image selected by the EFI El Torito entry of [061](https://github.com/kuro1337WStuff/hv/blob/1946d6eb6a49b74a591e3540a586d2bd96fcdc3e/journal/runs/061-l1-uart-thre.md); whole ISO SHA-256 `eb235223013a87484d38e3b2c459821895faa7c80175bdd90205123dff96171c`.

| File offsets (inclusive) | Field established from each PE header | Reference → candidate |
| --- | --- | --- |
| `0x00C0–0x00C1` | COFF `TimeDateStamp` | `1795631281` → `1795639925` |
| `0x0110–0x0112` | PE32+ optional-header `CheckSum` | `0xCCB7` → `0x1103F` |
| `0x246C–0x246D` | `.rdata`: `IMAGE_DEBUG_DIRECTORY.TimeDateStamp` | `1795631281` → `1795639925` |

The last field was identified by translating debug-directory RVA `0x3468` to file offset `0x2468`, then reading the timestamp at `+4` in its single 28-byte entry. Windows `MapFileAndCheckSumW` returned success and computed each stored checksum independently. The complete `.text`, `.data` and `.pdata` raw sections, section table, and all other file bytes matched. Controls exercised differences immediately outside the timestamp, in a section, at end-of-file and in malformed headers. References: [Microsoft PE/COFF](https://learn.microsoft.com/en-us/windows/win32/debug/pe-format), [debug directory](https://learn.microsoft.com/en-us/windows/win32/api/winnt/ns-winnt-image_debug_directory), [checksum API](https://learn.microsoft.com/en-us/windows/win32/api/imagehlp/nf-imagehlp-mapfileandchecksumw).
