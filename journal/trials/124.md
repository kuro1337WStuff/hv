# 124 · How many SMT siblings does Windows actually see on the 9950X?

**Windows 11 x64 build 26200 reported 16 physical cores, each with two logical processors.** The registry identified the development CPU as `AMD Ryzen 9 9950X 16-Core Processor`; it did not identify the topology. `GetLogicalProcessorInformationEx(RelationProcessorCore)` returned one sibling mask per core. A separate `GetActiveProcessorCount(ALL_PROCESSOR_GROUPS)` call returned **32**, agreeing with the union of those masks.

All 16 masks were in Windows group 0. They yielded pairs `(0,1)`, `(2,3)`, …, `(30,31)` within that group. The tool reports each identity as `group:number`; these are Windows logical-processor numbers, not APIC IDs or permanent hardware core IDs. A snapshot with sixteen cores and 32 logical processors is not enough on its own: a synthetic 1-thread core plus a 3-thread core kept the same totals but failed the target-shape check.

**Controls:** the five local fixture tests covered SMT off, sparse masks including bit 63, different groups, padded variable-length records, a missing core detected by an independent count, malformed or truncated records, and overlapping identities. The [hosted CPU job](https://github.com/kuro1337WStuff/hv/actions/runs/45736996082/job/139632524979) also passed those five tests using synthetic input on Linux. Only the local Windows run observed this CPU.

**Reproduce:** on x64 Windows, run `python -B lab/win_core_inventory.py` from [feature PR #165](https://github.com/kuro1337WStuff/hv/pull/165). `python -B -m unittest -v lab.tests.win_core_inventory_test` runs the portable fixtures.
