# 097 · Linux fallback PIT calibration on a virtual clock

**PASS — host only.** The legacy-PIC branch of Linux's fallback calculation returned **2,500,000 virtual kHz** for both its 10 ms and 50 ms configurations. This was a replay against a device model, not an execution of Linux or a measurement of either Ryzen processor.

[Reservation](https://github.com/kuro1337WStuff/hv/issues/13#issuecomment-7177681776) · [#78](https://github.com/kuro1337WStuff/hv/issues/78) · [implementation #82](https://github.com/kuro1337WStuff/hv/pull/82). Tested merge tree `950ae3023567d9fa568302e528a9b453ba1d6b0c`; landed on `feature/l1-handoff` at `50b804c0`. No firmware promotion to `main`.

The replay follows [`pit_calibrate_tsc` in Linux v6.18.60](https://github.com/gregkh/linux/blob/v6.18.60/arch/x86/kernel/tsc.c#L414-L491). It enabled the channel-2 gate, disabled the speaker, wrote `B0h` and both reload bytes, then read OUT2 from the shared PIT. Each low sample read cycles from the [095 virtual clock](095.md). The first high ended polling but **did not contribute cycles**. An external poll budget also limited frozen traces.

| Input / control | Checked observation |
|---|---|
| 11,931 reload, 10 µs spacing | 1,000 lows; last low +25,000,000 cycles; first high at 10,010,000 ns. |
| 59,659 reload, 10 µs spacing | 5,000 lows; last low +125,000,000 cycles; first high at 50,010,000 ns. |
| Only 999 lows | Rejected despite a max/min gap ratio of just 2. |
| Minimum gap 12,500 cycles | Maximum 125,000 accepted (exactly 10×); 125,002 rejected. |
| Offset sample grid | Last low +24,999,875 cycles; integer division returned 2,499,987 kHz. |
| Frozen after 10 µs | 1,200 low polls, port `61h = 01h`; budget exhausted, not a kernel rejection. A backward time input was refused without moving the clock. |

**Reproduce:** use an x64 MSVC Developer Command Prompt at the tested feature revision. Compile each of `lab\tests\pit_fallback_test.c`, `pit_cycle_clock_test.c` and `pit_shared_test.c` (all in `lab\tests`) with `cl /nologo /O2 /std:c11 /TC /W4 /WX`, then run each executable. All three passed from an isolated export. There is no native TSC sampling, VM admission, Linux clocksource selection, or evidence about guest timing from this trial.
