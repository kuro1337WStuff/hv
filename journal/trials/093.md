# 093 · Shared PIT input, independent clockevent and calibration channels

**Host PASS.** [Reservation](https://github.com/kuro1337WStuff/hv/issues/13#issuecomment-7177303750) · [#68](https://github.com/kuro1337WStuff/hv/issues/68) · [feature PR #71](https://github.com/kuro1337WStuff/hv/pull/71) · [tested integration](https://github.com/kuro1337WStuff/hv/tree/d0bf117ffc62bd8408f1cfacd8c3d931e795ee06), tree `702f983e16dfc99d2f8fe921be406fee5907107a`.

[091](091.md) tested the channel-0 modes. This fixture gives channel 0 and channel 2 the same **absolute number of completed input pulses**. I/O does not generate time. The command byte selects its channel on port `0x43`; count bytes reach their own channel on `0x40` or `0x42` even when the writes are interleaved. The [pinned Linux quick and fallback calibrators](https://github.com/gregkh/linux/blob/v6.18.60/arch/x86/kernel/tsc.c) supplied the channel-2 transactions, not a CPU clock or a guest verdict.

| Host control | Observation |
|---|---|
| Freeze channel 2 while channel 0 runs | Channel-2 count MSB changed `ff` → `fe` at pulse 269. Gating it off held the count at `feff`; channel 0 still issued its IRQ0 request at pulse 1204. |
| Finish a channel-0 one-shot and then disable it | The pending request survived disable and was accepted once. The two channel-2 fallback loads raised OUT2 at pulses 11932 and 71592 without another IRQ0. |
| Advance to `UINT64_MAX` with IRQ0 masked | Channel 2 read back `1236`; many channel-0 periods produced one pending request, not a queue of interrupts. |
| Repeat or refuse an operation | A repeated timestamp was inert. Backwards time, divergent starting cursors and unsupported I/O were refused without partial device updates. |

**Reproduce:** from the linked tree use an x64 MSVC Developer Command Prompt and compile `lab/tests/pit_shared_test.c`, `lab/tests/pit_periodic_test.c` and `lab/tests/pit_channel2_test.c` as separate C11 executables (`/O2 /std:c11 /W4 /WX`); run each. All three passed. The combined executable printed `PASS: shared PIT pulses, CH0 IRQ0 and CH2 calibration ports`.

No VM boot, physical TSC read, Linux clock selection or interrupt injection. [#72](https://github.com/kuro1337WStuff/hv/issues/72) tracks the separate virtual cycle-to-PIT ratio.
