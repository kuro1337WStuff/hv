# 110 · Can the linked Linux entry page be treated as immutable?

**Not from the on-disk hash.** The pinned kernel declares alternatives at three distinct places on that page. Five `.altinstructions` records cover **18 unique bytes**, not 30: two sites each have two declarations for the same six bytes. This is a host observation about potential writes, not evidence that any replacement was chosen or that a write occurred.

| Page-relative byte range (end excluded) | Size | Records, zero-based |
|---|---:|---|
| `[0x65c, 0x662)` | 6 | 1226 |
| `[0xa9d, 0xaa3)` | 6 | 1227, 1228 |
| `[0xc5d, 0xc63)` | 6 | 1229, 1230 |

The scanner read all 8,734 packed records. It used the signed displacement relative to the original field itself and the original length, including padding, as defined in [Linux v6.18.60 `alternative.h`](https://github.com/gregkh/linux/blob/v6.18.60/arch/x86/include/asm/alternative.h). It intersected each span with the linked virtual entry page `[0xffffffff83004000,0xffffffff83005000)` and counted overlapping bytes once. An independent reader decoded the two fields from separate byte columns, counted coverage byte-by-byte, and matched the indices and all four counts without using the scanner's interval-union routine.

**Reproduce** from [feature revision `78121a55`](https://github.com/kuro1337WStuff/hv/tree/78121a558d76c0c170a18e58cd77e2cc5fad4eab) with the [pinned `vmlinuz-virt` from 102](102.md). The 4,096-byte linked page retained the same disk hash as 102. It is not the decompressor entry page.

```sh
python -B -m unittest -v lab.tests.inspect_exec_layout_test
python -B -S lab/linux/inspect_exec_layout.py build/session-048-inputs/vmlinuz-virt
```

All **six host tests passed** on source tree `eeff6dfd5ccf0516f67d4738c65b0a6c7d023a02`. Controls included negative displacements, exact-boundary and empty spans, clipping across page edges, duplicate and overlapping records, an impossible address and a partial final record. The separate CLI ran on the retained 12,649,472-byte kernel, SHA-256 `1e8ac7aebfab3f0fcb443eae94ad320efbbda51be91b928c32ca1740b44ebe9d`.

**Decision:** do not infer immutability or grant execute permission from this inventory. It covers one table, not every kernel write mechanism, and says nothing about the other 4,078 bytes' lifetime. No kernel instruction ran, no NPT mapping changed, and there is no new cold-boot receipt.
