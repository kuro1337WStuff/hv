# 126 · Which cores share a Windows-visible L3 cache on the 9950X?

**Two unified L3 caches, each 32 MiB, each shared by eight complete SMT cores.** Windows 11 x64 build 26200 identified the CPU as `AMD Ryzen 9 9950X 16-Core Processor`. The tool joined Windows `RelationCache` group masks to the [124](124.md) core/sibling inventory; it did not infer memberships from capacity, ordering or CPU branding.

| Unified L3 size | Windows group | Logical processor numbers in its mask | Physical cores represented |
|---:|---:|---|---:|
| 33,554,432 bytes | 0 | 0 through 15 | 8 |
| 33,554,432 bytes | 0 | 16 through 31 | 8 |

The independent active count was 32. Every logical processor appeared exactly once, with no unknown member and no core split across caches. Two synthetic inputs kept the same 16 cores and 32 logical processors but changed the second cache from 32 to 96 MiB; the report distinguished them. Other controls retained the right core count but overlapped masks, omitted a pair, included a nonexistent processor or split siblings. None yielded exact coverage. Malformed records were not reported as absent caches.

**Build provenance mattered:** the first live CLI identified the kernel32 file build (`26100`) as the OS build. The corrected CLI reported `10.0.26200`, matching Windows `CurrentBuildNumber`, with identical cache masks. [Feature PR #171](https://github.com/kuro1337WStuff/hv/pull/171), final tested tree `c46a93248e3d9358e850f8aaa84b5015f0438991`; integration `d7ccb9b5`. [The hosted CPU job](https://github.com/kuro1337WStuff/hv/actions/runs/45738047437/job/139635968174) passed all ten tests, including legacy single-mask and multi-group fixtures. Only the local Windows run observed this CPU.

**Reproduce:** `python -B lab/win_core_inventory.py --l3` on an x64 Windows host; `python -B -m unittest -v lab.tests.win_core_inventory_test` for the portable fixtures. [Windows cache relationship](https://learn.microsoft.com/en-us/windows/win32/api/winnt/ns-winnt-cache_relationship) · [reservation](https://github.com/kuro1337WStuff/hv/issues/13#issuecomment-7180049423) · [issue #163](https://github.com/kuro1337WStuff/hv/issues/163).

Cache memberships are not hardware CCD identifiers, scheduler measurements or a benchmark. The asymmetric case was synthetic, not a measurement of the 9950X3D. No affinity change, VM or hypervisor launch.
