# 088 · Reading pinned init milestones from a bound serial capture

**Offline host tests passed. No Linux guest was booted or powered off.** [Work item #51](https://github.com/kuro1337WStuff/hv/issues/51) · [reservation](https://github.com/kuro1337WStuff/hv/issues/13#issuecomment-7176793757) · [implementation #54](https://github.com/kuro1337WStuff/hv/pull/54).

`lab.guest_tx_evidence.observe_init_milestones(directory, requested, review, raw)` first verifies the original attempt, media, broker events, reviewed frame, TX count/digest and overflow using `verify_guest_tx`. It then looks for three exact lines in the order emitted by the [pinned init](https://github.com/kuro1337WStuff/hv/blob/3876824ed7b26236a3230cd50174f3ce9cc92dbb/lab/linux/init). LF and CRLF are supported without changing byte offsets; a repeated or malformed milestone or an incomplete capture line is not accepted. TIMER checks the integer-second comparison used by init, not a floating-point delta. The [pinned kernel](https://github.com/gregkh/linux/blob/f45ed76d6791cf72ff1265ee93511175bbbc2f18/fs/proc/uptime.c) prints two fractional digits.

| Input | Observed result |
| --- | --- |
| Synthetic, separately bound test capture with unrelated serial bytes | USER (`pid=1`, kernel `6.18.60-0-virt`), TIMER (`9.99` → `10.00`) and SHUTDOWN started at byte offsets 32, 99 and 135. Original `ATTENTION` remained `ATTENTION`. The matched `COMPLETE` test likewise retained its original disposition. |
| Bound but invalid text | Reordered, repeated, truncated or quoted records, wrong PID/release, malformed uptime, signed overflow and non-increasing integer seconds were refused. `9.00` → `9.99` is not progress by init’s test. |
| Changed or missing evidence | Absent review, wrong attempt, substituted bytes/frame/events/worklist, count mismatch and overflow yielded no observations. |
| Actual archived [047](https://github.com/kuro1337WStuff/hv/blob/c50789a0dbe11690abed52f00a92d900775f7021/journal/test-report.md#047--polled-8250-compatible-serial-output) | The original UART evidence and `ATTENTION` binding were valid, but the eight bytes `L2:8250\n` contained no init markers. The observer refused with `expected three HV:P5: records`. This is not another boot. |
