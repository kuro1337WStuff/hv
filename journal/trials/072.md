## Reproduce without a VM

Use the test fixture from #21, x64 MSVC Developer Command Prompt and the existing `edk2-stable202502` `MdePkg\Include` tree. Produce the candidate with `git merge-tree --write-tree 97081ce264 f996fbc`; expected tree `a61881a3dd00493a0cb68b96267b67af86eda83d`. Export its `firmware/` using `git archive`. In a build directory, set `TESTS` to the fixture's `lab\tests`, `EDK` to the EDK include directory and `FW` to the selected `firmware` directory. Compile each time `FW` changes:

```bat
cl /nologo /O1 /Gy /std:c11 /W4 /WX /DHV_STANDALONE_L2 /DHV_PACKAGE /DHV_PIC_INIT /I"%FW%" /I"%EDK%\X64" /I"%EDK%" "%TESTS%\pic_observation_test.c" "%TESTS%\pic_observation_traps.c" /Fepic-observe.exe /link /OPT:REF
```

Run `pic-observe.exe legacy` for the original tree, `pic-observe.exe candidate` for the combined tree. Both exited zero. Neither command accepts a VM or device target.
